# 组件

> [English](components.md) | 简体中文

各客户端的核心组件（[客户端 §6.4](../../docs/clients.zh-CN.md#64-组件)）。每个客户端用 `gen/` 中的 tokens 原生实现它们；本文是各实现共享的规范。`代码` 形式的名称是 tokens：主题的 `color.*`、设备形态的 `layout.*`，以及 `typography.*`、`spacing.*`、`radius.*`、`duration.*` 与 `easing.*`。

## 状态

每个可交互组件都有以下状态；电视为每张卡片增加获得焦点状态。

| 状态 | 外观 |
| :--- | :--- |
| 默认 | 如下文所述 |
| 指针悬停 | 卡片的图片加上 2 pt 的 `color.accent` 边框，与图片相隔 1 pt；行、列表条目和无底色按钮在自身背景上叠加 `color.fill`，浅色主题下变暗，深色主题下变亮 |
| 获得焦点（电视、键盘） | 以 `easing.standard` 在 `duration.fast` 内放大到 `layout.focusScale`，带 `color.tvFocusShadow` 的阴影（偏移 12 pt，模糊 32 pt），图片加上 3 pt 的 `color.accent` 边框，与图片相隔 1.5 pt；其他平台的键盘焦点显示 2 pt 的 `color.focus` 边框 |
| 按下 | 内容不透明度降至 80% |
| 加载 | 与组件最终尺寸相同的 `color.surfaceRaised` 占位，内容到达时不发生移动 |
| 禁用 | 内容使用 `color.textDisabled` |
| 无图片 | 保留占位，从左上角叠加 `color.fill` 的淡灰渐变，至 70% 处消失，中央为所示内容的图标（电影、剧集、音乐等），`color.textTertiary`、不透明度 60%，宽为占位的四分之一，至多 56 pt；不在其上写标题 |

## 海报卡片

电影、剧集、季或合集的 2:3 卡片。

* **结构**：圆角 `radius.md` 的图片；其下为标题（`typography.headline`，一行）与副标题（`typography.footnote`，`color.textSecondary`，一行：年份或条目数）。
* **叠加层**：沿图片底边的观看进度条（3 pt，`color.progress` 叠在 `color.scrim` 上）；右上角的已看标记（图标 `played`，Fill）；剧集与季在该位置改为显示未看集数的 `color.accent` 徽标。
* **尺寸**：宽度 `layout.poster`；网格中宽度为可用空间除以能放下宽度不小于 `layout.poster` 的列数。
* **无图片时**：在 `color.surfaceRaised` 上居中显示 `typography.title3` 的标题。

## 缩略图卡片

剧集单集、视频或章节的 16:9 卡片。

* **结构**：圆角 `radius.md` 的图片；其下为标题（`typography.headline`），单集还有剧集与集数（`typography.footnote`，`color.textSecondary`，字符串 `item.episodeNumber`）。
* **叠加层**：同海报卡片，另在左下角显示未看完条目的剩余时间（`item.minutesLeft`）。
* **尺寸**：宽度 `layout.thumbnail`。

## 横向列表

带标题的一行卡片（继续观看、下一集、某媒体库最新内容）。

* **结构**：标题（`typography.title3`），桌面与触屏上带"更多"操作；其下为卡片，间距为 `layout.gutter` 的一倍半（电视上为 `layout.gutter`），首张与 `layout.margin` 对齐。
* **行为**：可用触摸、滚轮与触控板横向滚动；电视上焦点逐张移动，列表滚动以保持焦点卡片可见；使用鼠标时，标题栏末端的两个箭头把它向前、向后滚动大半个宽度，到头的一侧变暗，卡片放得下时都不显示；电视上没有箭头。
* **为空时**：没有条目的横向列表隐藏。

## 详情页头部

条目详情页的顶部。

* **结构**：背景图，没有时为剧集的剧照，再没有时为模糊的海报衬在海报本身之后；其左下部向该处加深，叠加剧集或季所属的剧集（其标志，链接到它）、剧集的集号、标志或标题（`typography.display`）、信息、评分与徽标、宣传语（`typography.headline`）、简介与操作。
* **信息**：一行（`typography.callout`）：年份，或剧集的年份（"2023–"）与季数、季的集数、剧集的播出日期、时长与至多三个类型；每个分隔符跟随其前的信息，使任何一行都不以分隔符开头。其下为带星标的社区评分、影评分数与白色描边的徽标：分级，所选版本的分辨率、动态范围与环绕声，有字幕时为 CC。
* **简介**：`typography.body`，三行（电视上两行），更长时带"更多"；"更多"在对话框中显示完整简介与宣传语，手机上则就地展开。
* **操作**：主操作为白底黑字，播放接下来的内容：电影或剧集为继续播放或播放；剧集或季为接下来要看的一集并带其集号，如"继续播放 S1 E2"。其旁为圆形按钮：有进度时的从头播放、附加内容中有预告片时的预告片（没有时为网上的预告片，在浏览器中打开）、收藏与已看，作品有多个版本或位于其他服务器时再加上版本菜单。其下为一行状态（`typography.footnote`）：进度条、该集的名称、剩余时间与预计结束时间。
* **下一集**：在剧集的各集中（只有特别篇时才计入特别篇），最后播放的一集未看完时为该集，否则为其后第一个未看的一集，再否则为第一个未看的一集，最后为第一集。
* **版本菜单**：胶囊按钮"版本 2160p"，向上打开各版本的菜单：每个版本以其文件名相对文件夹名多出的部分命名（"2160p"），附分辨率、动态范围、环绕声、容器与大小，所选版本打勾；其后为同一作品在用户其他服务器上的版本。
* **布局**：平板、桌面与电视把文字放在图片左侧；桌面上图片占窗口高度的 70%（520–700 pt），为直达侧边栏旁内容区边缘的矩形；电视上占屏幕的 86%，焦点从主操作开始，并隐藏标签。手机上图片为与屏幕同宽的正方形，向上延伸到透明的顶栏之下直至顶部，高度再加上顶栏的高度，其上为标志或标题、信息与徽标，操作与简介位于其下的页面中，主操作独占一行、占满宽度，位于圆形按钮之上。

## 详情页

头部之下依次为：

* **剧集**：剧集以胶囊列出各季，从下一集所在的季开始，下方为该季各集的剧集卡片横向列表，"查看全部"打开该季；剧集尚有可请求的季时，“请求更多”如发现的作品页那样选择它们；电视上焦点移到胶囊即选中它。季以剧集行列出各集。单集显示同季的其他各集，横向列表滚动到该集。
* **演职人员**：人物卡片的横向列表，演员按排序在前，每人一次，为其出演最久的角色，其后为创作者、导演与编剧；“查看全部”打开演职人员页。
* **预告片与花絮**：条目除主题曲与主题视频外的附加内容，以缩略图卡片的横向列表显示，每张带播放标记、名称、类别与时长，选中即播放；没有缩略图的附加内容使用条目的背景图。
* **合集**：属于合集的电影显示一条横幅：合集的背景图，没有时为电影的背景图，向左加深，"合集"在其名称之上，右侧为"查看合集"（圆角 14 pt）。
* **相似**：服务器上相似条目的海报横向列表。
* **推荐**：有 TMDB ID 的电影或剧集显示发现提供方的推荐，为作品卡片的横向列表，与发现的作品页相同。
* **详细信息**：左侧为宣传语、完整简介、如发现的作品页的六位主要职员（“查看全部职员”打开仅含职员的演职人员页）、以描边胶囊显示的关键词（条目的标签）与外部网站链接——电影或剧集为其发现的作品的标志，其他为胶囊；右侧先为评分——电影或剧集为其发现的作品的烂番茄、IMDb 与 TMDB 评分，各自打开其页面；其他条目或没有这些评分时，为满分 10 分带星标的观众评分与百分制的影评人评分，各自以大字置于 `color.fill` 上——再为各项信息（上映或播出日期、电影的院线、数字版与实体版发行在同一行并各带图标、最后与下集播出日期、状态、时长、分级、类型、制片厂或播出网络（前五个，带“显示更多”）、国家或地区（媒体库所存与元数据提供方所述相同时带国旗）、原始语言、原名、预算、票房、添加日期）与播放它的流媒体平台，每个平台为其标志与名称组成的胶囊，其下为所选版本的视频、音频、字幕、文件与大小，每项为说明文字（`typography.caption`，`color.textSecondary`）在上、值在下。类型、关键词与制片厂打开媒体库中具有该值的条目。优先显示媒体库为条目保存的信息，其缺少的由元数据提供方对其发现的作品所述补全。对管理员，头部显示电影或剧集下载的进度，其获取部分在下载之前列出它的请求，可批准或拒绝。

## 演职人员页

条目或发现的作品的全部演职人员，从其详情打开：标题上方是返回它的链接，其下是人物卡片网格的各部分——按排序的演员、客串演员，再按职务列出剧组（创作者、导演、编剧、原著、制片人、音乐、指挥、作词、艺术家、旁白、其他职员），已知时卡片注明所饰角色或具体职务名称。服务器的人物打开其人物页，其他人物打开其发现的人物页。条目或发现的作品的“查看全部职员”打开仅含职员的此页，标题为“全部职员”，如 Seerr 的职员页。

## 剧集卡片

剧集横向列表中的一集。

* **结构**：缩略图卡片的图片，宽 `layout.thumbnail`；其下为集号（"S1 E2"，下一集用 `color.accentText`）与时长、播出日期（`typography.footnote`，`color.textSecondary`）、标题（`typography.headline`）与三行简介（`typography.footnote`）。
* **叠加层**：同缩略图卡片。

## 剧集行

季列表中的一集。

* **结构**：左侧为缩略图卡片的图片，至多占行宽的三分之一（140 pt 到 `layout.thumbnail`）；集号（下一集用 `color.accentText`）、标题（`typography.headline`）、时长与播出日期（`typography.footnote`，`color.textSecondary`）以及三行简介（`typography.callout`）。
* **叠加层**：同缩略图卡片。

## 人物卡片

演员或职员。

* **结构**：圆形照片（`radius.full`）、姓名（`typography.callout`）与角色（`typography.footnote`，`color.textSecondary`），各至多两行。
* **无照片时**：与卡片的“无图片”占位相同（状态），图标为 `profile`。

## 头像

菜单、用户列表与 Home 中用户或账户的图像。

* **结构**：圆形（`radius.full`），内有名称的首个字符，大写、半粗，字号为圆直径的 0.42。
* **颜色**：所有人相同，与背景协调而不突兀：圆为 `color.fillSelected`，首字母为 `color.textSecondary`，随主题变化；以首字母区分不同的人。

## 音轨选择器

播放器与详情页中的音轨与字幕选择器。

* **结构**：音轨列表，每项显示语言名称与详细信息（`typography.footnote`，`color.textSecondary`：编码、声道、强制字幕、听障字幕）；选中项带勾选标记。字幕列表以 `player.subtitlesOff` 开头。
* **呈现**：Apple 平台与桌面上是菜单，Android 手机上是底部面板，电视上是侧边面板。

## 状态视图

页面或列表的空、错误、离线与加载状态。

* **结构**：图标（48 pt，`color.textTertiary`：`error`、`offline`）、标题（`typography.title3`：`state.empty`、`state.error`、`state.offline`）、可选的说明（`typography.body`，`color.textSecondary`）与可选的操作（`action.retry`）。
* **加载**：内容形状已知时显示其占位（见"状态"），如货架的卡片；否则（如正在载入的页面）显示活动指示器，居中于页面所占的空间：28 pt 圆内的八根辐条，`color.textTertiary`，绕圈不透明度从 20% 渐变到不透明，每步转过一根辐条，0.9 秒转一圈，减少动态效果时静止。它在加载开始 0.4 秒后才出现，快速到达的内容不会先闪出它。正在加载的内容不以服务器的名称或地址代替。首屏显示应用标志。
* **离线**：已下载的条目仍列在该视图下方。

## 助手

语音助手（[助手 §9](../../docs/assistant.zh-CN.md#9-客户端)）：一个独立悬浮在页面上的光球，以及旁边的卡片：用户说了什么、助手的回答、它做了什么。没有对话框、标题栏、关闭按钮或文本框：助手是用来说话的。[`prototypes/assistant.html`](prototypes/assistant.html) 在桌面与手机上、两种主题下画出光球的每种状态与每种卡片。

* **布局**：桌面、平板与电视上光球悬浮在右上角，84 pt，卡片在其下方堆叠，宽 380 pt，间隔 `spacing.sm`，最新的在最下；手机上光球悬浮在底部中央，卡片在其上方堆叠，宽为屏幕宽减去两侧各 `spacing.sm`，最新的在最上。光球旁的状态胶囊（卡片材质上的 `typography.footnote`，`radius.full`）说明它在等什么："正在载入…"、"正在聆听…"或如何说话，其余时候隐藏。背后的页面保持原样，助手关闭后即可使用。
* **光球**：一个内部流动着彩色光的玻璃球，没有边框或背景：三个模糊的色团，品红、青与蓝，各为一个径向渐变，以各自的速度绕中心旋转，裁在球内（思考时为环），底为蓝色的球体。其上是玻璃：光从上方落下，越近下缘越暗，左上有一块柔和的椭圆反光；球没有边缘光或描边。深色主题中球体为深蓝，颜色相加，核心发出白光，球外散着一圈淡淡的光晕；浅色主题中颜色更深（品红 `#EB28A0`、青 `#00AAEB`、蓝 `#5A46F5`），在蓝色上相互叠放，带一层小的蓝色阴影，使核心保留颜色，边缘也不会在页面上晕开。四个值驱动它，约 0.15 秒内缓动到各状态的值：大小、散开度（色团彼此绕开多远）、速度与亮度；音频电平（用户说话时取麦克风的，助手说话时取播放的）使它膨胀、色团散开。减少动态效果时光球静止，保持各状态的大小与亮度。
* **状态**：光球显示语音会话的状态，取自其事件（[助手 §8.6](../../docs/assistant.zh-CN.md#86-协议)）：

| 状态 | 何时 | 光球 |
| :--- | :--- | :--- |
| 开启中 | 从按下到麦克风的第一段音频 | 小而暗，缓慢呼吸；胶囊显示正在载入 |
| 聆听 | 有音频而用户未说话：`ready` 前后，以及回答之后 | 完整大小，颜色缓慢流动，轻微呼吸；胶囊显示正在聆听 |
| 用户说话 | `user_started` → `user_stopped`，其间 `transcript` 增长 | 随麦克风电平胀缩，颜色散开 |
| 停顿 | 用户安静下来但这一轮未结束（尚无 `user_stopped`） | 收拢并缓慢旋转 |
| 思考 | `user_stopped` 或 `run` → `bot_started`，其间有 `tool` | 聚成快速旋转的环 |
| 说话 | `bot_started` → `bot_stopped` | 随播放电平起伏 |
| 被打断 | `interrupt` | 收缩并闪一下白光，然后转为用户说话 |
| 未聆听 | 松开按住说话，或会话结束而卡片仍在 | 完整大小与颜色，流动很慢，不呼吸；胶囊说明如何说话 |
| 错误 | `error`，或无法连上会话 | 摇晃一次并泛红，然后转为未聆听 |
| 结束 | 会话关闭或空闲超时，且没有待选择或确认的内容 | 与卡片一起缩小淡出 |

* **卡片**：卡片材质——深色主题为 72% 的 `color.surfaceOverlay`，浅色主题为 74% 的白色，叠在页面的模糊之上，1 pt `color.border`、`radius.xl` 与 `elevation.level3`——以 `duration.slow` 与 `easing.emphasized` 升入位置：
  * **对话**：用户说的话，然后是回答，都是 `typography.body`。用户的话为 `color.textSecondary`，随 `transcript` 增长，定稿后末尾加一个 `color.textTertiary` 的箭头"›"；回答的词从 `color.textTertiary` 开始，随说出转为 `color.textPrimary`，按播放的节奏（不说出时一次全部显示）。
  * **工具**：每个 `tool` 一行：26 pt `radius.sm` 的方块，内为 `color.accent` 的工具图标，底为 16% 的强调色；其摘要（`typography.footnote`，`color.textSecondary`）；运行时为活动指示器，之后为 `color.success` 的对勾或 `color.danger` 的叉。
  * **结果**：可选的条目，带编号以便用户说"第二个"，每行为编号（`color.textTertiary`）、海报与标题及年份；用语音、点击或轻点选择一个即对它执行操作。
  * **确认**：问题，以及并排的取消与确认（`color.accent`），也可用语音回答。
  * **错误**：以 `color.danger` 的文字显示消息。
  新一轮的卡片取代上一轮的；结果与确认保留到被回答为止。
* **关闭**：自动关闭——会话结束后，或回答之后没有待选择或确认的内容时（结束状态）数秒后，指针停在卡片上或触摸卡片时暂停；点击或轻点光球与卡片以外的任何地方；按 Esc、遥控器的返回键或 Android 的返回键。每种方式都结束会话，光球与卡片在 `duration.slow` 内一同淡出。
